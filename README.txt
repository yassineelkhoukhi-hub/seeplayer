SEE PLAYER TV — Official website starter

Files:
- index.html: home page
- privacy.html: starter privacy policy
- terms.html: terms of use
- style.css: responsive purple/black theme
- assets/: supplied app icon and screenshots

Free hosting:
1. Create a public GitHub repository, e.g. seeplayer-website.
2. Upload all files and the assets folder (keep the same folder structure).
3. In the repository open Settings > Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. GitHub Pages will show the public website URL.

IMPORTANT BEFORE PUBLISHING:
- The Privacy Policy is a starter draft, not a verified statement of app data practices.
- Review the actual app code, permissions, network behavior and all SDKs (including any bundled libraries).
- Update the policy to disclose actual collection, sharing, storage, deletion, analytics, advertising and crash-reporting practices.
- Confirm the support email is correct and monitored.
- Use only screenshots/content you own or have permission to publish.
- Do not claim ownership of third-party channels, movies, shows, logos or media shown in playlists.
